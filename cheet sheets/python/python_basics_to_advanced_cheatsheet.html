Python Cheat Sheet

Python Basics to Advanced

Quick reference guide based on the Python brochure PDF covering core syntax, OOP, data structures, modules, and advanced concepts.

1. Python Basics

  • Python is easy to read and widely used for automation, app development, AI, and data work.
  • Run scripts using IDLE, VS Code, or Jupyter Notebook.
  • Use variables and data types: int, float, str, bool.
  • Use input() for user input and print() for output.
name = "Python"
age = 25
price = 99.99
is_active = True

print(name, age, price, is_active)
user = input("Enter your name: ")

2. Operators

  • Arithmetic: +, -, *, /, %, **
  • Relational: ==, !=, >, <, >=, <=
  • Logical: and, or, not
  • Assignment: =, +=, -=, *=
  • Identity and membership: is, in, not in
print(5 + 3)
print(10 > 7 and 2 < 5)
print("a" in "apple")

3. Control Flow

  • Conditional statements: if, elif, else
  • Loops: for and while
  • Loop control: break, continue, pass
  • Nested loops are supported.
  • Comprehensions: list, dict, set
for i in range(1, 6):
if i % 2 == 0:
print(i, "even")
else:
print(i, "odd")

Core Data Structures

Strings

  • Immutable sequence of characters.
  • Useful methods: upper(), lower(), split(), strip(), replace().
  • Indexing and slicing supported.
s = "python"
print(s[0])
print(s[1:4])

Lists

  • Mutable ordered collection.
  • Methods: append(), pop(), sort(), reverse(), extend().
  • Supports indexing and slicing.
nums = [1, 2, 3]
nums.append(4)
print(nums)

Tuples

  • Immutable sequence.
  • Used when values should not change.
point = (10, 20)
print(point[0])

Sets

  • Stores unique values.
  • Useful for unions, intersections, differences.
a = {1, 2, 3}
b = {3, 4, 5}
print(a | b)

Dictionaries

  • Key-value pairs.
  • Methods: keys(), values(), items(), get().
student = {"name": "Amit", "age": 22}
print(student["name"])

Stacks and Queues

  • List can be used for stack behavior.
  • collections.deque is useful for queues.
from collections import deque
q = deque([1, 2, 3])
q.append(4)

Functions, Modules, and Packages

Functions

  • Define using def.
  • Parameters, return values, default args, keyword args.
  • Variable-length args: *args, **kwargs.
  • Lambda functions are concise one-line functions.
def add(a, b=0): return a + b print(add(5)) print(add(5, 10))

Scopes

  • Local scope
  • Global scope
  • nonlocal scope inside nested functions
x = 10 def demo(): global x x = 20 return x

Recursion

  • A function calls itself.
  • Need a base condition to stop.
def fact(n): if n == 0: return 1 return n * fact(n - 1)

Modules & Packages

  • Import built-ins such as math, datetime, random, os, sys.
  • Create your own modules.
  • Use pip to install external packages.
import math import datetime print(math.sqrt(16))

File Handling and Exceptions

File Operations

  • open() reads and writes files.
  • Modes: r, w, a, rb, wb.
  • Use with open() as f: for safe file handling.
with open("sample.txt", "r") as f: text = f.read() print(text)

Error Handling

  • Errors and exceptions are different.
  • Use try, except, else, finally.
  • Use raise to trigger an exception.
  • Custom exceptions can be created.
try: x = 10 / 0 except ZeroDivisionError: print("Cannot divide by zero") finally: print("Cleanup complete")

Object-Oriented Programming (OOP)

Core OOP Concepts

  • Class and object
  • __init__ constructor
  • Instance, class, and static methods
  • Inheritance: single, multiple, multilevel
  • Polymorphism, encapsulation, abstraction
class Animal: def __init__(self, name): self.name = name def speak(self): return "Sound" class Dog(Animal): def speak(self): return "Bark"

Abstraction

  • Hide internal details and expose only necessary behavior.
  • Use abc module for abstract base classes.
from abc import ABC, abstractmethod class Shape(ABC): @abstractmethod def area(self): pass

Advanced Python

Iterators & Generators

  • Use yield to create generators.
  • Generators are memory-efficient.
def squares(n): for i in range(n): yield i * i

Decorators & Context Managers

  • Decorators modify behavior of functions.
  • with makes context managers easy to use.
def decorator(fn): def wrapper(): print("before") fn() print("after") return wrapper

Regular Expressions

  • Use re module for pattern matching.
  • Common operations: match, search, findall.
import re print(re.findall(r"\d+", "abc123def456"))

Logging, Virtual Environments, Threads

  • Use logging for application logs.
  • Use venv to isolate environments.
  • Explore multithreading and multiprocessing.
  • Understand memory management and garbage collection.

Data Handling and Libraries

JSON & CSV

  • Use json for JSON files.
  • Use csv for CSV file handling.

NumPy

  • For numerical arrays and vectorized calculations.
  • Very useful in data science and ML.

Pandas

  • For tabular data analysis.

Matplotlib

  • For visual data representation.
  • Create charts and graphs for EDA.
