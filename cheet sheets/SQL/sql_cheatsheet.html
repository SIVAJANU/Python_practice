SQL Cheat Sheet

SQL Basics to Advanced

Quick-reference guide for SQL essentials, joins, subqueries, transactions, performance tuning, and real-world database practices.

1. SQL Basics

  • SQL stands for Structured Query Language.
  • Categories: DDL, DML, DQL, DCL, TCL.
  • Core concepts: database, schema, table, row, column.
  • Common data types: INT, VARCHAR, DATE, DECIMAL, BOOLEAN.

2. Database Creation

  • Create a database.
  • Create/drop tables with schema definitions.
  • Use ALTER to modify structure.
CREATE DATABASE company_db; USE company_db; CREATE TABLE employees ( id INT PRIMARY KEY, name VARCHAR(50), salary DECIMAL(10,2) );

3. Data Types

  • INT / BIGINT
  • VARCHAR / CHAR
  • DATE / DATETIME / TIMESTAMP
  • DECIMAL / FLOAT

DDL: Data Definition Language

CREATE TABLE

  • Defines a table structure.
  • Includes columns and constraints.
CREATE TABLE customers ( customer_id INT PRIMARY KEY, name VARCHAR(100) NOT NULL, city VARCHAR(50) );

ALTER TABLE

  • Add or drop columns.
  • Modify column properties.
ALTER TABLE customers ADD email VARCHAR(100); ALTER TABLE customers DROP COLUMN email;

DROP TABLE / TRUNCATE

  • DROP TABLE removes the table definition and data.
  • TRUNCATE removes all rows but keeps the table.

DML: Data Manipulation Language

INSERT

INSERT INTO employees (id, name, salary) VALUES (1, 'Alice', 50000);

UPDATE

UPDATE employees SET salary = 55000 WHERE id = 1;

DELETE

DELETE FROM employees WHERE id = 1;

Bulk Insert

  • Used to load many rows quickly.
  • Common in ETL and data loading tasks.

DQL: Data Query Language

SELECT Basics

SELECT * FROM employees; SELECT name, salary FROM employees;

WHERE Clause

SELECT * FROM employees WHERE salary > 50000; SELECT * FROM employees WHERE city IN ('Delhi', 'Mumbai');

Operators

  • =, <, >, <=, >=
  • BETWEEN
  • LIKE
  • IN

Sorting & Filtering

SELECT DISTINCT city FROM employees; SELECT * FROM employees ORDER BY salary DESC;

Aliases

SELECT name AS employee_name, salary AS annual_salary FROM employees;

Functions

Aggregate Functions

  • COUNT()
  • SUM()
  • AVG()
  • MAX()
  • MIN()
SELECT COUNT(*) FROM employees; SELECT AVG(salary) FROM employees;

Scalar Functions

  • UPPER(), LOWER()
  • LEN(), ROUND()
  • String and numeric transformations.

Date Functions

  • NOW()
  • DATEADD()
  • DATEDIFF()

Conversion Functions

  • CAST()
  • CONVERT()
  • Used to convert between data types.

Joins

INNER JOIN

  • Returns only matching rows.
SELECT o.order_id, c.name FROM orders o INNER JOIN customers c ON o.customer_id = c.customer_id;

LEFT JOIN

  • Returns all left table rows and matching right rows.

RIGHT JOIN

  • Returns all right table rows and matching left rows.

FULL OUTER JOIN

  • Returns all rows from both tables.

SELF JOIN

  • A table joins with itself.

CROSS JOIN

  • Produces the Cartesian product.

Constraints

Primary Key

  • Uniquely identifies each row.

Foreign Key

  • Links one table to another.

UNIQUE

  • Ensures all values are distinct.

NOT NULL

  • Prevents null values.

CHECK

  • Limits values based on a condition.

DEFAULT

  • Assigns a default value when not specified.

Subqueries and Set Operations

Subqueries

  • Single-row subqueries
  • Multi-row subqueries with IN / ANY / ALL
  • Correlated subqueries
  • EXISTS check
SELECT * FROM employees WHERE salary > (SELECT AVG(salary) FROM employees);

Set Operations

  • UNION / UNION ALL
  • INTERSECT
  • EXCEPT / MINUS
